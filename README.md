# RISC-V-emulator

![CI](https://github.com/pinks111/RISC-V-emulator/actions/workflows/ci.yml/badge.svg)

Минималистичный эмулятор RISC-V (RV32IM) на C++20.

> **Статус:** в разработке. Декодер инструкций реализован,
> выполнение инструкций пишется.

## Цели

- Реализовать базовый целочисленный набор инструкций RV32I.
- Сделать код небольшим, читаемым и покрытым тестами.
- Обеспечить воспроизводимую сборку (CMake, Docker) и примеры программ.

## Структура проекта

```
src/        исходники эмулятора (декодер, процессор, память, main)
tests/      модульные тесты (GoogleTest)
examples/   примеры программ (.bin)
tools/      скрипты для сборки примеров
```

## Сборка

Требуется: компилятор с поддержкой C++20, CMake 3.14+.

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## Использование

```bash
rv32emu program.bin
```

Эмулятор загружает бинарный файл в память с адреса 0, начинает выполнение
с `pc = 0` и работает до вызова `exit`, ошибки или превышения лимита шагов.

Пример (после сборки):

```bash
./build/rv32emu examples/hello.bin
```

Код возврата эмулятора равен коду, с которым программа вызвала `exit`.
Ненулевой код может означать и ошибку эмулятора (плохая инструкция,
обращение вне памяти, неверный запуск), сообщение об ошибке выводится в `stderr`.

## Системные вызовы

Программы общаются с эмулятором через `ecall`. Номер вызова кладётся
в `a7` (x17), аргументы в `a0`–`a2` (x10–x12), та же конвенция, что и в Linux.

| a7 | Вызов | Аргументы | Результат |
|----|-------|-----------|-----------|
| 93 | `exit` | a0 = код выхода | останавливает эмулятор |
| 64 | `write` | a0 = fd (1 или 2), a1 = адрес буфера, a2 = длина | a0 = записано байт, или -1 при ошибке |

## Поддерживаемые инструкции

**Реализовано:**

- RV32I: арифметика, логика, сдвиги и сравнения (R- и I-форматы), `lui`, `auipc`,
  переходы (`jal`, `jalr`, ветвления), загрузка и сохранение
  (`lb`, `lh`, `lw`, `lbu`, `lhu`, `sb`, `sh`, `sw`), `ecall`.
- RV32M: `mul`, `mulh`, `mulhsu`, `mulhu`, `div`, `divu`, `rem`, `remu`
  с поведением при делении на ноль и переполнении, как в спецификации.

**Не реализовано** (эмулятор останавливается с сообщением об ошибке):

- `fence`, `ebreak` и CSR-инструкции;
- сжатые инструкции (расширение C), прерывания и привилегированные режимы;
- загрузка ELF-файлов (на вход принимается только сырой бинарник).

## Docker

Сборка и запуск без установки компилятора и CMake. Нужен только Docker.

```bash
docker build -t rv32emu .
docker run --rm rv32emu /examples/hello.bin
```

Тесты (отдельная стадия сборки):

```bash
docker build --target test -t rv32emu-test .
docker run --rm rv32emu-test
```

Запуск своей программы (файл с хоста монтируется в контейнер):

```bash
# Linux / macOS
docker run --rm -v "$PWD":/data rv32emu /data/program.bin

# Windows (PowerShell)
docker run --rm -v "${PWD}:/data" rv32emu /data/program.bin
```
